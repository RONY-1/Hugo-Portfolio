### Project Overview
Developed an autonomous robotics prototype capable of detecting ambient fire hazards in enclosed facilities. The system activates localized water/chemical spraying and dispatches instant SMS alerts over GSM networks.

### Features
- Real-time flame and temperature sensor array integration.
- Automated navigation and obstacle avoidance.
- Emergency alert notifications via GSM modem.
