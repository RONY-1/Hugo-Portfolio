### Overview
This project is a high-performance personal academic portfolio template powered by **Hugo** and **PaperMod**. It features fast rendering, built-in search indexing, zero heavy JavaScript dependencies, and dark mode persistence.

### Features
- **Instant Search**: Integrated Fuse.js client-side search.
- **Academic & Industry Layout**: Dedicated sections for publications, projects, blog posts, and resume.
- **GitHub Pages Ready**: Includes automated GitHub Actions workflow for zero-config deployment.
